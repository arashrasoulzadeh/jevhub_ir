مرجع HTTP API

مرجع کامل endpoint ارزیابی TypeSafe.

آخرین به‌روزرسانی: مدل: jev-1.13.0 منبع بازبینی‌شده در منبع انگلیسی

یک state را در برابر نگاشتی از questions تایپ‌شده ارزیابی کنید و answers ساختاریافته بگیرید؛ یکی برای هر پرسش.

Endpoint ارزیابی

بدنه‌ی درخواست

statestring | object | arrayالزامی

محتوای مورد ارزیابی. رشته‌ی ساده برای متن، یا داده‌ی ساختاریافته برای لاگ‌های چت، رکوردها یا وضعیت فعلی اپلیکیشن. State را ببینید.

modelstring

مدلی که درخواست را پردازش می‌کند. از "jev-latest" استفاده کنید. مدل‌ها را ببینید.

questionsmap<string, Question>الزامی

نگاشتی از اشیای Question تایپ‌شده. کلیدها را خودتان انتخاب می‌کنید و پاسخ‌ها زیر همان کلیدها برمی‌گردند. کلید به مدل فرستاده نمی‌شود و در استنتاج استفاده نمی‌شود.

انواع Question

همه‌ی انواع type و instructions مشترک دارند و هر کدام criteria خودش را اضافه می‌کند. instructions می‌تواند رشته، شیء یا آرایه باشد؛ پرسش را در یک فیلد و داده را در فیلدهای دیگر بگذارید و با نام در بک‌تیک به آن ارجاع دهید.

type"noul"

پرسش بله/خیر؛ احتمال «بله» را برمی‌گرداند.

instructionsstring | object | array

پرسش بله/خیر برای ارزیابی.

criteria.true / criteria.falsestring | object | arrayاختیاری

معنای بله (مقدار نزدیک ۱) و خیر (نزدیک ۰).

type"choice"

یک گزینه از مجموعه‌ای که تعریف می‌کنید؛ گزینه‌ی انتخاب‌شده و توزیع کامل احتمال را برمی‌گرداند.

instructionsstring | object | array

آنچه مدل باید تصمیم بگیرد.

criteriamap<string, string | object | array | null>

نگاشت گزینه به توصیف روبریک؛ برای گزینه‌ی بی‌نیاز از توضیح null. حداکثر ۲۵۵ گزینه.

type"score"

رتبه‌دهی state روی روبریکی که تعریف می‌کنید؛ مقداری وزن‌دار با احتمال روی سطوح برمی‌گرداند.

instructionsstring | object | array

آنچه مدل باید رتبه دهد.

criteriaarray<string | object | array>

آرایه‌ی مرتب توصیف سطوح؛ دست‌کم ۲ و حداکثر ۱۰.

بدنه‌ی پاسخ

modelstring

مدلی که ارزیابی را انجام داده (شناسه‌ی نسخه‌دار).

answersmap<string, Answer>

یک Answer برای هر پرسش، با همان کلیدهای questions.

usage{ input_tokens, output_tokens }

مصرف توکن درخواست.

انواع Answer

هر پاسخ یک type متناظر با پرسشش دارد. پاسخ‌های Choice و Score همچنین confidence بین ۰ و ۱ دارند.
