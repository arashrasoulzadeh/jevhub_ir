Agent skill

اسکیل آماده برای Claude Code، Codex و دیگر محیط‌های ایجنت.

آخرین به‌روزرسانی: مدل: jev-1.13.0 منبع بازبینی‌شده در منبع انگلیسی

اسکیل TypeSafe به ایجنت کدنویسی شما کانتکست کامل API، پریمیتیوها و الگوها را می‌دهد تا یکپارچه‌سازی‌های درست بسازد؛ از جمله اینکه در هر فراخوانی پرسش‌های زیادی بگذارد. متن اسکیل را می‌توانید در GitHub بخوانید.

چرا این اسکیل لازم است

بدون این اسکیل، ایجنت کدنویسی شما فقط دانش عمومی‌اش را درباره‌ی TypeSafe دارد — که ممکن است قدیمی یا اشتباه باشد. با نصب اسکیل، ایجنت به این‌ها دسترسی مستقیم پیدا می‌کند:

  • شکل دقیق درخواست و پاسخ HTTP API و SDKهای پایتون و جاوااسکریپت.
  • تفاوت Choice، Score و Noul و اینکه کدام‌یک برای چه پرسشی مناسب است.
  • الگوهای معماری رایج مثل پخش گمانه‌زنانه و مسیریابی با آستانه‌ی اطمینان.
  • عادت درست «پرسش‌های زیاد در یک فراخوانی» به‌جای یک پرسش در هر فراخوانی — عادتی که ایجنت‌های کدنویسی بیشتر از انسان‌ها در دام آن می‌افتند.
