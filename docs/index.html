شروع

معرفی

Jev مدل پرچم‌دار TypeSafe و نخستین مدل System One است. state و پرسش‌های تایپ‌شده بفرستید؛ پاسخ‌های ساختاریافته بگیرید که کدتان مستقیماً از آن‌ها استفاده کند.

شروع سریع

ترجیح می‌دهید مستقیم شروع کنید؟ هر آنچه برای شروع فوری لازم دارید این‌جاست.

Jev و ایجنت‌های کدنویسی

Jev وقتی با یک ایجنت کدنویسی کار می‌کنید چه هست (و چه نیست).

مفاهیم

System One

مدل‌های System One تصمیم‌های سریع و ساختاریافته برای نرم‌افزار می‌گیرند.

State

state چیست، چگونه ساختارش دهیم و چطور کانتکست لازم را به مدل System One بدهیم.

چگونه با TypeSafe بسازیم

نرم‌افزار مبتنی بر هوش مصنوعی را طوری طراحی کنید که کنترل در دست کد بماند و System One فقط تصمیم‌های محدود و ساختاریافته بگیرد.

مقدمه‌ای بر هوش مصنوعی

چرا TypeSafe مدل‌های تصمیم‌گیر با احتمال‌های کالیبره آموزش می‌دهد، نه مدل‌هایی بهینه برای تولید متن.

پرسش‌ها (پریمیتیوها)

مرور کلی

سه نوع پرسش TypeSafe، پاسخ‌های تایپ‌شده‌ی آن‌ها، نحوه‌ی انتخاب بینشان و پرسیدن چند پرسش با هم.

Choice

انتخاب یک گزینه از مجموعه‌ای تعریف‌شده؛ همراه با احتمال هر گزینه و اطمینان.

Score

رتبه‌دهی محتوا روی سطوح مرتب و توصیفی؛ همراه با score، احتمال هر سطح و اطمینان.

Noul

یک پرسش بله/خیر که احتمال «بله» بودن پاسخ را برمی‌گرداند.

پیشرفته: ساختار

دستورالعمل‌ها، گزینه‌های Choice، سطوح Score و معیارهای Noul همگی ساختار JSON می‌پذیرند.

اطمینان

Confidence

TypeSafe چگونه میزان قطعیت را گزارش می‌کند، چه فرقی با احتمال دارد و چگونه با آن رفتار سیستم را کنترل کنیم.

الگوها

مرور الگوها

الگوهای معماری برای ساختن سیستم با TypeSafe.

پخش گمانه‌زنانه

پرسش‌های زیاد، از جمله گمانه‌زنانه، را در یک فراخوانی بفرستید و بگذارید کد تصمیم بگیرد چه چیزی مرتبط است.

مسیریابی با آستانه‌ی اطمینان

اطمینان را محور دوم قرار دهید: پاسخ می‌گوید «چه»؛ اطمینان می‌گوید «آیا اقدام کنیم».

امتیازدهی ترکیبی

یک قضاوت پیچیده را به امتیازهای اتمی بشکنید و با وزن‌هایی که در کد کنترل می‌کنید ترکیب کنید.

مسیریابی نیت

درخواست‌ها را طبقه‌بندی و هر کدام را به بهترین پردازشگر بفرستید: منطق قطعی، یک LLM تخصصی یا انسان.
