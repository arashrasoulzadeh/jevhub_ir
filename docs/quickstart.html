شروع سریع

ترجیح می‌دهید مستقیم شروع کنید؟ هر آنچه برای شروع فوری لازم دارید این‌جاست.

آخرین به‌روزرسانی: مدل: jev-1.13.0 منبع بازبینی‌شده در منبع انگلیسی

امتحانش کنید: Playground

  1. Playground را باز کنید و وارد شوید.
  2. هر متنی را به‌عنوان state بچسبانید.
  1. یک پرسش اضافه کنید. یک پرسش Noul را امتحان کنید: "Does this message express urgency?"
  1. پرسش‌های بیشتری اضافه کنید. Noul، Choice و Score را در یک فراخوانی ترکیب کنید و همه‌ی نتایج را یک‌جا ببینید.

فراخوانی کنید: API

  1. کلید API خود را از داشبورد بگیرید.
  2. یک درخواست POST به endpoint بفرستید.
  3. برای همه‌ی جزئیات، مرجع API را ببینید.

نمونه‌ی دستور cURL

بدنه‌ی درخواست و پاسخ

کد بنویسید: SDK پایتون

SDK را نصب کنید (نیازمند Python نسخه‌ی ۳٫۱۰ یا بالاتر):

از SDK استفاده کنید. کلاینت TYPESAFE_API_KEY را از محیط می‌خواند و به‌طور پیش‌فرض jev-latest را فراخوانی می‌کند.

برای گزینه‌های نصب و استفاده‌ی دقیق، بخش SDKها را ببینید.

با ایجنت بسازید: Agent skill

اسکیل TypeSafe را نصب کنید تا ایجنت کدنویسی شما با API، پریمیتیوها و الگوها آشنا شود:

در ایجنت‌های دیگر، هنگام نصب ایجنت خود را انتخاب کنید. نصب به‌صورت پیش‌فرض محلیِ پروژه است؛ برای نصب سراسری -g اضافه کنید. سپس به ایجنت کدنویسی خود بگویید هنگام ساختن از اسکیل TypeSafe استفاده کند. جزئیات بیشتر در بخش Agent skill.
