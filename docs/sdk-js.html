SDK جاوااسکریپت / TypeScript

SDK جاوااسکریپت و TypeScript برای TypeSafe AI؛ نیازمند Node.js ۲۲ یا جدیدتر.

آخرین به‌روزرسانی: مدل: jev-1.14.0 منبع بازبینی‌شده در منبع انگلیسی

TYPESAFE_API_KEY را در محیط تنظیم کنید، سپس کلاینت را بسازید. تایپ پاسخ‌ها از روی پرسش‌ها استنتاج می‌شود. بسته شامل ESM، CommonJS و declarationهای TypeScript است.

توابع کمکی

تابعامضاتوضیح
choice()choice(instructions, criteria)پرسشی که بین گزینه‌های نام‌دار انتخاب می‌کند؛ criteria نگاشت برچسب به توصیف یا null.
score()score(instructions, criteria)پرسش Score با روبریک مرتب؛ دست‌کم دو توصیف با اندیس از صفر.
noul()noul(instructions?, criteria?)پرسش بله/خیر با توصیف اختیاری true و false.

پیکربندی کلاینت

apiKeystring

کلید API؛ در صورت نبود از TYPESAFE_API_KEY خوانده می‌شود.

baseURLstring

ریشه‌ی API؛ سپس TYPESAFE_BASE_URL و در نهایت https://api.typesafe.ai.

defaultModelstring

مدل پیش‌فرض؛ سپس TYPESAFE_DEFAULT_MODEL و در نهایت jev-latest.

dangerouslyAllowBrowserboolean

اجازه‌ی استفاده در مرورگر که کلید API را در معرض کاربران صفحه قرار می‌دهد. پیش‌فرض: false.

defaultHeaders / fetch / logger…

هدرهای اضافه، پیاده‌سازی سفارشی fetch برای تست یا transport، و لاگر.

کلید API را هرگز در کد سمت مرورگر قرار ندهید. فراخوانی‌ها را از سرور یا یک API میانی انجام دهید.

تصاویر و Box (آزمایشی)

تصویر را با image() از بایت فایل یا یک Blob (مثل File) یا با Image.fromBase64() بسازید. فقط PNG و JPEG؛ قالب را API از بایت‌ها تشخیص می‌دهد و بقیه (مثل WebP و GIF) را با BadRequestError رد می‌کند. پشتیبانی تصویر آزمایشی است و با هدر TypeSafe-Danger-Zone-Images: true فعال می‌شود (در defaultHeaders کلاینت یا گزینه‌ی headers یک فراخوانی). سه روش استفاده، قابل ترکیب با هم:

هر تصویر یک بار فرستاده می‌شود، هرچند بار که استفاده شود. تصویر در template literal بدون برچسب (مثل `Compare ${upload}`) پیش از ارسال با TypeSafeError رد می‌شود؛ هر نام در assets هم باید در درخواست بیاید. از جداکننده‌های متمایز مثل <delivered> استفاده کنید.

پرسش box محل چیزی را پیدا می‌کند؛ box پاسخ لبه‌ها را به‌صورت کسری از ارتفاع (top، bottom) و عرض (left، right) دارد و confidence وقتی API گزارش نکند null است. برای box مدل jev-preview را بدهید. جزئیات: Box.

فشرده‌سازی درخواست

کلاینت بدنه‌های ۱ KiB و بزرگ‌تر را با zstd فشرده می‌کند؛ بدنه‌های کوچک‌تر در یک segment TCP جا می‌شوند و بدون فشرده‌سازی می‌روند. zstd به Node.js ‏۲۲٫۱۵ یا جدیدتر نیاز دارد و روی runtimeهای دیگر همه‌ی بدنه‌ها بدون فشرده‌سازی فرستاده می‌شوند. برای خاموش کردن (مثلاً APIای که بدنه‌ی فشرده نمی‌پذیرد) new TypeSafeClient({ compression: false }) بدهید.
