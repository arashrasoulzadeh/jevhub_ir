خطاها و محدودیت نرخ

خطاها از کدهای وضعیت استاندارد HTTP با بدنه‌ی JSON توصیفی استفاده می‌کنند.

آخرین به‌روزرسانی: مدل: jev-1.13.0 منبع بازبینی‌شده در منبع انگلیسی
وضعیتمعنا
401 Unauthorizedکلید API موجود نیست یا نامعتبر است. هدر Authorization را بررسی کنید.
422 Unprocessable Entityبدنه‌ی درخواست اعتبارسنجی نشد؛ مثلاً فیلد الزامی جا افتاده یا پرسش بدشکل است. بدنه‌ی پاسخ فیلد مشکل‌دار را مشخص می‌کند.
429 Too Many Requestsاز محدودیت نرخ گذشته‌اید. کمی صبر کنید و دوباره تلاش کنید.
529 OverloadedTypeSafe موقتاً پربار است. پس از کمی تأخیر دوباره تلاش کنید.

مدیریت محدودیت نرخ

با دریافت 429 یا 529، به‌جای تلاش فوری، با exponential backoff دوباره تلاش کنید. SDKهای کلاینت این کار را خودکار انجام می‌دهند؛ اگر از SDK با سیاست پیش‌فرض retry استفاده می‌کنید نیازی به مدیریت اضافه نیست.
