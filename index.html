Jev مدل پرچم‌دار TypeSafe و نخستین مدل System One است. یک state و چند پرسش تایپ‌شده بفرستید و پاسخ‌هایی ساختاریافته با احتمال و اطمینان بگیرید که کد شما مستقیماً روی آن‌ها تصمیم بگیرد. این‌جا مستندات کامل آن را به زبان فارسی می‌خوانید.

وقتی کد شما تصمیم لازم دارد، نه پاراگراف

مدل‌های زبانی بزرگ برای تولید متن جهت خواندن انسان طراحی شده‌اند. Jev برای تصمیم‌هایی ساخته شده که نرم‌افزار مصرف می‌کند.

مدل زبانی (LLM) برای خروجی ساختاریافته

  • متن توکن‌به‌توکن تولید می‌شود و باید آن را parse کنید.
  • ممکن است مقداری خارج از گزینه‌های مجاز برگرداند.
  • عدم قطعیت واقعی و کالیبره‌شده در خروجی نیست.
  • پرسش‌های بیشتر یعنی کانتکست طولانی‌تر و زمان بیشتر.

Jev (مدل System One)

  • پاسخ‌ها ذاتاً تایپ‌شده‌اند؛ هیچ parse کردنی لازم نیست.
  • همیشه محدود به گزینه‌ها و سطوحی است که خودتان داده‌اید.
  • احتمال‌های کالیبره‌شده و confidence برای تصمیم‌گیری امن.
  • پرسش‌ها موازی و مستقل‌اند؛ بدون «پوسیدگی کانتکست» بین پرسش‌ها.
در چهار قدم

از کلید API تا اولین تصمیم

کلید API بگیرید

از داشبورد TypeSafe کلید بسازید و آن را در متغیر محیطی TYPESAFE_API_KEY قرار دهید.

SDK را نصب کنید

پایتون: pip install typesafe-sdk — جاوااسکریپت: npm install @typesafe-ai/sdk

state و پرسش‌ها را تعریف کنید

محتوای مورد ارزیابی را در state و قضاوت‌های اتمی را به شکل Choice، Score و Noul بنویسید.

در کد تصمیم بگیرید

با if، آستانه‌ها و وزن‌ها پاسخ‌ها را ترکیب کنید و بر اساس confidence خودکار عمل کنید یا به انسان ارجاع دهید.
